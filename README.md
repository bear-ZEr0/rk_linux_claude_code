# Claude Code 自定义配置

这个仓库用于存放 Claude Code 的自定义技能和脚本。

## 目录结构

```
my-custom/
├── skills/          # 自定义技能（slash commands）
└── scripts/         # 自定义脚本工具
```

## 使用说明

### Skills
存放自定义的 Claude Code 技能，可以通过 `/skill-name` 的方式调用。

### Scripts
存放各种工具脚本，避免重复创建相同功能的脚本。

## 注意事项

- 所有脚本都应该有清晰的注释和使用说明
- 及时整理和归档，避免重复劳动
- 定期同步到 git 仓库
