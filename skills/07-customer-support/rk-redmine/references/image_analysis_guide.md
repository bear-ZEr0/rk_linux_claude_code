# Redmine 图片内容分析使用指南

本指南详细介绍如何使用rk-redmine skill的智能图片分析功能，帮助用户准确提取Redmine问题中的图片内容。

## 快速开始

### 基本使用流程

```bash
# 1. 获取问题信息并下载附件
python3 scripts/get_issue_info.py <问题ID>

# 2. 查看生成的报告
cat ./redmine_issues_<问题ID>/issue_report.md

# 3. 找到需要分析的图片
ls ./redmine_issues_<问题ID>/ | grep -E '\.(png|jpg|jpeg|gif)$'
```

### 完整的图片分析流程

```bash
# 步骤1: 获取问题并生成初始报告
python3 scripts/get_issue_info.py 593691 --dir /tmp/analysis

# 步骤2: 查看报告中的图片引用
cat /tmp/analysis/redmine_issue_593691/issue_report.md | grep '!\(.*\)\.png!'

# 步骤3: 分析每个图片（示例）
调用MCP工具:zai-mcp-server analyze_image进行分析，提示词参考下面的图片类型和分析策略模版，原则是准确提取内容，不要添加评论等。

# 步骤4: 将分析结果替换到报告中
# 手动编辑 issue_report.md，将 !图片名! 替换为分析结果
```

## 图片类型和分析策略

### 1. 代码截图分析

**典型场景**：补丁对比、代码差异、Git diff

**提示词模板**：
```
请准确提取图片内容。图片包含代码内容，请精确识别并完整还原所有代码，保持原有格式、缩进和注释。如果是代码对比或差异，请分别列出原始代码和修改后的代码，用'原始：'和'修改：'明确标注。如果有红框标记，请提取红框内的代码并标注位置。
```

### 2. 日志信息分析

**典型场景**：串口输出、kernel log、Android logcat、系统启动日志

**提示词模板**：
```
请准确提取图片内容。图片包含日志信息，请逐行完整提取日志内容，保持时间戳、进程名、日志级别、错误信息等所有原始格式。如有红框标注，请提取红框内的日志行并标注位置。
```

### 3. 技术问题现象分析

**典型场景**：界面UI异常、显示问题、错误现象、花屏、紫屏

**提示词模板**：
```
请准确提取图片内容。图片显示了技术问题现象，请简洁描述：1）界面上显示的具体问题或异常 2）问题出现的位置（如左上角、全屏等）3）任何可见的错误信息或状态指示 4）如果有红框标注，请准确描述红框指向的内容。
```

### 4. 技术原理图分析

**典型场景**：硬件框图、信号流向图、接口连接图、架构图

**提示词模板**：
```
请准确提取图片内容。图片是技术原理图，请提取：1）所有模块和组件的名称 2）模块间的连接关系（如A连接到B）3）接口类型标注 4）信号流向指示 5）所有文字标注和参数。如有红框标注，请提取红框内容并说明其位置和重点。
```

### 5. 波形数据分析

**典型场景**：示波器波形、信号时序图、频谱图

**提示词模板**：
```
请准确提取图片内容。图片是波形图，请提取：1）波形的关键参数（频率、幅度、时间等）2）波形特征描述 3）所有标注信息 4）异常点位置。如有红框标注，请提取红框内的波形特征。
```

### 6. 设备规格分析

**典型场景**：规格书、支持格式表、技术参数表

**提示词模板**：
```
请准确提取图片内容。图片显示了设备支持的格式信息，请精确提取所有文字、数字、格式规范、分辨率、刷新率等技术参数。保持原有的格式和布局。如果是列表或表格形式，请按行列结构提取。如果有红框标注，请提取红框内的内容并标注位置。
```
## 最佳实践

1. **上下文分析**：始终根据图片周围的文字来理解图片内容
2. **渐进式分析**：先进行基础内容提取，再根据需要深入分析
3. **格式保持**：尽量保持原始格式，特别是代码和表格
4. **重点突出**：注意红框、高亮等标记的重要信息
5. **验证结果**：对比原始图片验证提取的准确性
