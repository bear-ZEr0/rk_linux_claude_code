# 补丁简报项目字段指南

本文档说明补丁简报（Patch Briefing）项目的特殊字段及其处理方式。

## 项目信息

- **项目ID**: 572
- **项目名称**: 补丁简报
- **Tracker ID**: 12
- **Tracker 名称**: 补丁简报

## 补丁简报特有字段

补丁简报项目包含以下特殊的自定义字段，与普通FAE项目不同：

### 1. Component (字段ID: 2)
- **类型**: 单选文本
- **说明**: 补丁所属的技术模块
- **常见值**: PCIe, HDMI, Camera, Audio, Video, Display, USB, Network等

### 2. 补丁类型 (字段ID: 106)
- **类型**: 单选文本
- **说明**: 补丁的类别
- **可选值**:
  - FIX: 修复问题
  - FEATURE: 新功能
  - OPTIMIZATION: 性能优化
  - REFACTOR: 代码重构

### 3. 可能受影响的芯片 (字段ID: 77)
- **类型**: 多选列表
- **说明**: 该补丁可能影响的芯片型号
- **值类型**: 芯片ID数组（需要映射到芯片名称）
- **映射规则**: 见 `configs/field_mappings.json`
- **示例**:
  - 输入: `["147", "158", "143"]`
  - 输出: `RK3568, RK3576, RK3588`

### 4. 补丁作者 (字段ID: 89)
- **类型**: 多选用户列表
- **说明**: 补丁的作者
- **值类型**: 用户ID数组（需要映射到用户名）
- **示例**:
  - 输入: `["224"]`
  - 输出: `Lin Shawn`

### 5. 补丁仓库:分支 (字段ID: 86)
- **类型**: 文本
- **说明**: 补丁提交的仓库分支
- **示例**: `develop-6.1`, `master`, `android12-rk3588`

### 6. 补丁 Change-Id (字段ID: 88)
- **类型**: 文本
- **说明**: Gerrit Change-Id，用于关联Gerrit提交
- **格式**: `I[0-9a-f]{40}`
- **示例**: `I0a11297b7efbf7a6dc574c968f1731f35f27822d`

### 7. 问题相关 Redmine 项目:# (字段ID: 87)
- **类型**: 文本
- **说明**: 关联的Redmine Issue ID
- **格式**: 逗号分隔的Issue ID列表
- **示例**: `593691, 594123`

### 8. 问题描述 (字段ID: 90)
- **类型**: 长文本
- **说明**: 问题的详细描述

### 9. 问题原因 (字段ID: 91)
- **类型**: 长文本
- **说明**: 问题的根本原因分析

### 10. 解决方法 (字段ID: 92)
- **类型**: 长文本
- **说明**: 解决问题的方法和补丁内容

### 11. 测试情况 (字段ID: 93)
- **类型**: 文本
- **说明**: 测试结果
- **常见值**: `pass`, `fail`, `pending`, `partial pass`

### 12. 补丁影响 (字段ID: 94)
- **类型**: 文本
- **说明**: 补丁的影响范围和副作用
- **示例**: `无`, `可能影响启动速度`, `需要清除缓存`

### 13. 接收情况 (字段ID: 95)
- **类型**: 多选列表
- **说明**: 补丁的接收状态
- **可选值**:
  - 1: 已接收
  - 2: 未接收
  - 3: 部分接收

## 字段ID映射配置

所有字段ID到名称的映射存储在 `configs/field_mappings.json` 中：

```json
{
  "chip_ids": {
    "143": "RK3588",
    "144": "RK3588S",
    "147": "RK3568",
    "150": "RK3528",
    "151": "RK3562",
    "158": "RK3576",
    ...
  },
  "custom_field_names": {
    "77": "可能受影响的芯片",
    "89": "补丁作者",
    "87": "问题相关 Redmine 项目:#",
    "95": "接收情况"
  },
  "patch_acceptance_status": {
    "1": "已接收",
    "2": "未接收",
    "3": "部分接收"
  }
}
```

## 脚本自动处理

`get_issue_info.py` 脚本会自动：

1. **加载映射配置**: 从 `configs/field_mappings.json` 加载所有映射
2. **转换芯片ID**: 将芯片ID数组转换为芯片名称列表
3. **转换用户ID**: 将用户ID数组转换为用户真实姓名
4. **转换状态ID**: 将接收状态ID转换为中文描述
5. **跳过空字段**: 空值字段不会显示在报告中

## 示例输出

### API原始数据
```json
{
  "custom_fields": [
    {
      "id": 77,
      "name": "可能受影响的芯片",
      "multiple": true,
      "value": ["147", "158", "143", "144", "150", "151"]
    },
    {
      "id": 89,
      "name": "补丁作者",
      "multiple": true,
      "value": ["224"]
    }
  ]
}
```

### 转换后的报告输出
```markdown
- **可能受影响的芯片**: RK3568, RK3576, RK3588, RK3588S, RK3528, RK3562
- **补丁作者**: Lin Shawn
```

## 搜索补丁简报

搜索补丁简报项目的技巧：

```bash
# 按芯片型号搜索
python3 scripts/search_by_keyword.py "RK3588 补丁" 20

# 按Component搜索
python3 scripts/search_by_keyword.py "PCIe 补丁" 20

# 按问题关键词搜索
python3 scripts/search_by_keyword.py "开关机测试异常" 15

# 组合搜索
python3 scripts/search_by_keyword.py "RK3568 HDMI FIX" 20
```

## 注意事项

1. **芯片ID映射**: 如果遇到未知的芯片ID，会显示为 `芯片ID_XXX`，需要更新 `configs/field_mappings.json`
2. **用户名缓存**: 脚本会从issue数据中自动缓存用户名，避免额外API调用
3. **空字段处理**: 空字段（如未填写的"接收情况"）不会显示在报告中
4. **Change-Id关联**: 可以使用Change-Id在Gerrit系统中查找对应的代码提交
