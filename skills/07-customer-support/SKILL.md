# Redmine 问题跟踪

## 何时激活

- 用户说"查看 Redmine 问题"、"redmine 工单"
- 用户说"查看我的问题"、"待处理问题"
- 用户说"帮我回复问题"

## 包含的技能

| 技能 | 说明 | 触发关键词 |
|------|------|-----------|
| [rk-redmine](rk-redmine/SKILL.md) | Redmine 问题查询、回复、补丁简报 | redmine, 工单, 问题跟踪 |

## 功能列表

### 1. 问题列表查看

获取分配给当前用户的问题，按状态和优先级分类展示。

### 2. 问题分析

- 分析问题描述，提取关键信息
- 识别问题类型（Bug、需求、咨询）
- 评估处理优先级

### 3. 处理建议

根据问题类型和历史经验，生成处理建议。

### 4. 回复模板

生成专业的问题回复模板，支持多种场景。

## 问题分类

### 按状态分类

| 状态 | 说明 | 处理方式 |
|------|------|----------|
| 新建 | 新提交的问题 | 需要确认和分配 |
| 进行中 | 正在处理 | 继续跟进 |
| 已解决 | 已修复待验证 | 等待客户确认 |
| 已关闭 | 处理完成 | 归档 |
| 已拒绝 | 非问题或重复 | 说明原因 |
| 反馈 | 需要更多信息 | 等待客户回复 |

### 按优先级分类

| 优先级 | 响应时间 | 说明 |
|--------|----------|------|
| 紧急 | 4 小时内 | 生产环境故障、阻塞性问题 |
| 高 | 1 工作日 | 重要功能异常 |
| 中 | 3 工作日 | 一般问题 |
| 低 | 1 周内 | 优化建议、小问题 |

### 按类型分类

| 类型 | 说明 | 处理流程 |
|------|------|----------|
| Bug | 功能缺陷 | 复现 → 定位 → 修复 → 验证 |
| 功能 | 新需求 | 评估 → 排期 → 开发 → 交付 |
| 支持 | 技术咨询 | 分析 → 回复 → 跟进 |
| 文档 | 文档问题 | 确认 → 更新 → 通知 |

## 问题分析流程

### 步骤 1: 获取问题列表

```
GET /issues.json?assigned_to_id=me&status_id=open
```

### 步骤 2: 解析问题信息

提取关键字段：
- 问题 ID
- 标题
- 描述
- 优先级
- 状态
- 创建时间
- 更新时间
- 项目
- 跟踪类型

### 步骤 3: 智能分类

根据标题和描述自动识别：
- 问题类型（Bug/功能/咨询）
- 涉及模块（SPI/CAN/UART 等）
- 紧急程度

### 步骤 4: 生成处理建议

根据问题类型生成建议：
- Bug: 需要复现步骤、日志信息
- 功能: 需要详细需求说明
- 咨询: 可直接回复或提供文档链接

## 回复模板

### 模板 1: 确认收到

```markdown
您好，

感谢您反馈此问题，我们已收到并开始处理。

**问题编号**: #{{issue_id}}
**当前状态**: 进行中
**预计响应**: {{response_time}}

如有补充信息，请直接回复此工单。

祝好
{{author}}
```

### 模板 2: 需要更多信息

```markdown
您好，

感谢您的反馈。为了更好地定位问题，请提供以下信息：

1. **SDK 版本**: 您使用的 SDK 版本号
2. **硬件平台**: MCU 型号和开发板型号
3. **复现步骤**: 详细的操作步骤
4. **日志信息**: 相关的错误日志或截图

收到信息后我们会尽快处理。

祝好
{{author}}
```

### 模板 3: 问题已解决

```markdown
您好，

您反馈的问题已解决，请查收：

**问题原因**: {{root_cause}}
**解决方案**: {{solution}}
**修复版本**: {{fix_version}}

请更新到最新版本验证，如仍有问题请重新打开此工单。

祝好
{{author}}
```

### 模板 4: 非问题/预期行为

```markdown
您好，

经过分析，您描述的现象是预期行为：

**说明**: {{explanation}}
**参考文档**: {{doc_link}}

如有其他疑问，欢迎继续反馈。

祝好
{{author}}
```

### 模板 5: 需求已记录

```markdown
您好，

感谢您的建议，我们已记录此需求：

**需求描述**: {{requirement}}
**评估状态**: 待评估
**预计排期**: {{schedule}}

后续有进展会及时更新，感谢您的支持。

祝好
{{author}}
```

## 配置说明

使用前需要先配置 Redmine 连接信息。

### 方式 1: 交互式配置

```
/config redmine
```

按提示输入 Redmine 地址、账号密码等信息。

### 方式 2: 直接编辑配置文件

编辑 `rk-redmine/configs/redmine_config.json`，详见 [`rk-redmine/configs/`](rk-redmine/configs/) 目录。

### 常用 API

| 操作 | 方法 | 端点 |
|------|------|------|
| 获取问题列表 | GET | /issues.json |
| 获取问题详情 | GET | /issues/{id}.json |
| 更新问题 | PUT | /issues/{id}.json |
| 添加评论 | POST | /issues/{id}.json |

## 最佳实践

### DO
- ✅ 及时响应紧急问题
- ✅ 回复前先分析问题
- ✅ 使用专业的回复模板

### DON'T
- ❌ 不要忽略紧急问题
- ❌ 不要回复过于简单
- ❌ 不要重复询问相同信息
- ❌ 不要长时间不更新状态
