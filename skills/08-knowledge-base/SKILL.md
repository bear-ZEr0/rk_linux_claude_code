# 知识库

本目录包含文档资料和知识管理相关的技能。

## 包含的技能

| 技能 | 说明 | 触发关键词 |
|------|------|-----------|
| [documentation-center](documentation-center/) | 文档中心 | 查文档, FAE文档, 硬件文档 |
| [rk-samba-share](rk-samba-share/) | Samba 共享访问 | 共享文件, NAS |
| [training-center](training-center/) | 培训资料 | 培训, 学习资料 |

## 文档中心子目录

| 目录 | 说明 |
|------|------|
| `redmine-fae-docs` | Redmine FAE 文档（DDR/eMMC/UFS AVL 等） |
| `rk-hardware-docs` | 硬件相关文档 |
| `rk-module-docs` | 模块开发文档 |

## 快速导航

### 需要查找文档？

- **FAE 文档** → [documentation-center/redmine-fae-docs](documentation-center/redmine-fae-docs/)
- **硬件文档** → [documentation-center/rk-hardware-docs](documentation-center/rk-hardware-docs/)
- **模块文档** → [documentation-center/rk-module-docs](documentation-center/rk-module-docs/)

### 需要访问共享资源？

→ 使用 [rk-samba-share](rk-samba-share/)

### 需要培训资料？

→ 访问 [training-center](training-center/)

## 使用说明

每个子目录可能包含独立的 SKILL.md 和辅助脚本，请查看对应目录获取详细信息。
