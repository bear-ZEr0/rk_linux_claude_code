## 搜索建议
如果目标芯片型号未在上述列表中找到：
1. 使用`list_directory "$SID" "/03_对外发布文件"`浏览所有可用芯片目录
2. 使用部分型号号进行搜索，如"RK35"而不是完整型号
3. 检查是否有新的芯片系列或命名变更
